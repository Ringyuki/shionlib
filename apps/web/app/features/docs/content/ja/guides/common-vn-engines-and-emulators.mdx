## はじめに

このガイドは、「ダウンロードしたゲームをどのエミュレーター/ランタイムで起動すべきか」を素早く判断するためのものです。

基本ルールは 2 つです。

- Windows 実行ファイルなどのネイティブ版があるなら、まずネイティブ実行を優先する。
- エミュレーターが必要な場合は、公開ソースがあり継続メンテナンスされているプロジェクトを優先する。

## 早見対応

Android / iOS リソースには **エンジン** のラベルが付きます。  
現在のラベル値は **吉里吉里（KRKR）** / **ONScripter** / **Artemis** / **その他** です。

このラベルはリソースのエンジン種別を示すもので、「必ずこの 1 つのアプリだけを使う」という意味ではありません。

![リソースカードのエンジン表示](/assets/images/download-games/ja/engine@2x.webp)

- 吉里吉里（KRKR） / ONScripter / Artemis（Android）：まず Tyranor 最新版を使用  
  [Tyranor 2.3.3 APK](https://t.shionlib.com/tools/Tyranor%202.3.3.APK)
- 吉里吉里（KRKR） / ONScripter（iOS）：App Store で対応エミュレーターを各自インストール。
- その他：リソースの説明に従って実行方法を選択。

最新版の Tyranor は、KRKR・ONS・Artemis の代表的なケースをカバーできます。配布ページに特定パッチや実行方法の指定がある場合は、そちらを優先してください。

## プラットフォーム別の推奨

### Windows

- まずネイティブ起動を優先。
- 配布ページに特定環境やパッチ指定がある場合は、その手順を優先。

### Android

- まずリソースカードの「エンジン」ラベル（吉里吉里（KRKR） / ONScripter / Artemis / その他）を確認。
- 吉里吉里（KRKR） / ONScripter / Artemis：まず Tyranor 2.3.3 を使用。
- その他、または非互換時：リソースの説明に従って切り替える。

### iOS

- 現時点で Tyranor の iOS 版はありません。
- iOS ユーザーはラベルに合わせて App Store から KRKR / ONS エミュレーターをインストールしてください。
- Artemis / その他 ラベルの場合は、リソースの説明を優先してください。

## よくある質問

### 起動はするが黒画面/クラッシュする

まず同じエンジン向けの別バージョンのエミュレーターを試し、その後にリソースの説明で特定パッチまたは特定バージョン指定がないか確認してください。

### エンジンが判別できない

まずリソースの説明を確認します。記載がない場合は、フォルダ構成と起動ファイル名から判断し、それでも不明ならコメント欄/ディスカッションで配布者に確認してください。
