## 攻略を見る

ゲームエントリーページで上部の **攻略** タブをクリックすると、そのゲームの公開済みの攻略をすべて確認できます。

各攻略には、作者、言語、ルート数、更新日時が表示されます。攻略を選ぶと、その説明を読み、各ルートを切り替えることができます。ルート内の各手順と、セーブおよびロードの位置が順に表示されます。

## 攻略を書く

攻略タブで **攻略を書く** ボタンをクリックすると（ログインが必要）、作成ページが開きます。各ユーザーは 1 つのゲームにつき 1 件の攻略を書くことができます。すでに書いている場合、ボタンは **自分の攻略を編集** に変わります。

1 件の攻略は 2 つの部分で構成されます：

- **説明** — 任意。おすすめの攻略順や注意事項などを紹介するためのもので、太字、ネタバレ、リンクに対応しています
- **ルート** — 1 件の攻略には複数のルートを含めることができ、各ルートには次の内容があります：
  - **ルート名** — 必須
  - **キャラクター** — 任意。そのゲームのキャラクターから、このルートに対応するキャラクターを選びます
  - **解放条件** — 任意。先にクリアする必要のあるルートを指定するか、その他の条件を記入できます
  - **手順** — 1 行に 1 手順。少なくとも 1 手順を入力します
  - **エンディング** — 任意

手順では次の書き方を使用できます：

| 書き方                                             | 意味                                        |
| -------------------------------------------------- | ------------------------------------------- |
| `セーブ 1`                                         | ここでスロット 1 にセーブします             |
| `ロード 1`                                         | スロット 1 のセーブデータをロードします     |
| `#` または `※` で始まる行、および `END` で終わる行 | メモ                                        |
| `選択肢の文 \| 補足`                               | `\|` より後の文字がこの手順の補足になります |

手順の横の **プレビュー** には、入力に合わせて攻略の実際の表示が反映されます。画面の幅が狭い場合は、**編集** と **プレビュー** を切り替えて確認します。ルートをドラッグすると順序を変更できます。

![攻略の作成。左に手順、右にプレビュー](/assets/images/walkthrough/ja/write@2x.webp)

作成が完了したら、**下書きを保存** または **公開** を選べます。

## 下書きと公開

| 操作         | 状態     | 表示範囲         |
| ------------ | -------- | ---------------- |
| 下書きを保存 | 下書き   | 自分にのみ表示   |
| 公開         | 公開済み | すべての人に表示 |

下書き状態の攻略には **下書き** のマークが表示され、あなたにのみ表示されます。いつでも戻って編集を続け、公開できます。公開済みの攻略も **下書きに戻す** で取り下げることができます。

## 攻略を編集する

攻略の作者は、自分の攻略をいつでも編集できます。ゲームの攻略タブで **自分の攻略を編集** をクリックするか、プロフィールページの攻略一覧から攻略を開いてください。

編集後も同様に、下書きとして保存するか再度公開するかを選べます。攻略の更新日時もそれに合わせて変わります。

## 審査

**公開** をクリックしても、攻略はすぐには公開されず、まず **審査中** の状態になり、システムが自動的に内容の審査を行います。

審査を通過すると、攻略の状態は自動的に公開済みに変わり、すべての人に表示されます。審査を通過しなかった場合、攻略には **審査を通過していません** と表示され、引き続き非表示のままとなります。作者には、通過しなかった理由を説明するシステムメッセージが 1 件届きます。

> 通常、審査は公開後の短時間で完了します。長時間「審査中」の状態が続く場合は、管理者に連絡してください。

## 攻略を削除する

作成ページの **<Ellipsis />** メニューで **攻略を削除** を選び、確認すると、その攻略は完全に削除されます。この操作は元に戻せません。

## プロフィールページで攻略を見る

プロフィールページを開いて **攻略** タブに切り替えると、あなたが書いたすべての攻略を確認できます。各記録には対応するゲーム、ルート数、更新日時が表示され、下書きと審査中の攻略には状態のマークが付きます。

他のユーザーのプロフィールページの攻略ページを開いた場合は、そのユーザーの公開済みの攻略のみが表示されます。
