## LunaBox とは

[LunaBox](https://box.lunarain.site) は高速・美麗・多機能な軽量ビジュアルノベル管理ツールです。ダウンロード機能だけでなく、ゲームライブラリの整理、プレイ時間の記録、さらにはビルトイン AI アシスタントによるプレイ習慣の分析まで行えます。

主な機能：

- **ゲーム管理** — カスタム分類と柔軟なメタデータ管理でライブラリを整理
- **プレイ時間トラッキング** — セッションを自動記録し、多次元の統計・グラフを生成
- **AI 分析** — ビルトイン AI がプレイ習慣を分析し、エンターテイメントレポートを生成
- **クラウドバックアップ** — S3・OneDrive 対応で安全なデータ同期・バックアップ
- **ダウンロード連携** — 自動解凍・チェックサム検証・レジューム対応

## LunaBox のインストール

公式サイトから LunaBox をダウンロード・インストールしてください：**https://box.lunarain.site**

現在、Windows 版は 2 種類あります：

- **インストーラー版（setup）**: 一般ユーザーに推奨されます。インストール時に `lunabox://` プロトコルの登録が自動で試行されるため、通常はそのままプッシュできます。データの保存先は既定で `%APPDATA%\LunaBox` です。
- **ポータブル版（portable）**: 展開するだけで使えますが、初回利用前に `lunabox://` プロトコルを手動で登録する必要がある場合があります。データの保存先は既定でプログラムディレクトリです。

後からポータブル版のフォルダーを移動した場合、Windows を再インストールした場合、またはインストーラー版がプロトコル経由で LunaBox を起動できなくなった場合は、以下のコマンドで再登録できます。

```powershell
# lunacli があるディレクトリに移動して、プロトコルを登録する
.\lunacli.exe --register-protocol

# lunacli を PATH に追加している場合は、そのまま実行できる，インストール版は環境変数の登録を自動的に処理します
lunacli --register-protocol
```

[LunaBox のドキュメント](https://box.lunarain.site/features/cli.html) も参照してください。

> LunaBox は現在 **Windows** のみ対応しています。

## Shionlib で LunaBox を無効または有効にする

LunaBox はデフォルトでダウンロードメニューに表示されます。無効にする手順：

1. **設定** → **ダウンロード**（または `/user/settings/download`）を開く
2. **ゲーム管理ツール** で **LunaBox** を探す
3. そのスイッチをオフにする

無効にすると、ダウンロードメニューに LunaBox の項目が表示されなくなります。同じページで、**LunaBox に送る** を既定のダウンロード方法に設定することもできます。設定後は、**ダウンロード** ボタンをクリックすると直接送信されます。

![ダウンロード設定のゲーム管理ツール](/assets/images/account-settings/ja/download@2x.webp)

## LunaBox でダウンロードする

1. 任意のゲームページを開き、**ダウンロード** タブでダウンロードしたいリソースとファイルを見つける
2. ファイルの右側にある **ダウンロード** ボタンの横の矢印をクリックして、**ほかのダウンロード方法** メニューを開く
3. メニューから **LunaBox に送る** を選び、ダウンロードタスクを送信する
4. ページがロボットでないことの確認を自動で行い、確認が済むとタスクは自動的に LunaBox に送られます
5. ブラウザから LunaBox を開くかどうかを尋ねられたら、許可を選ぶ
6. LunaBox に切り替えると、ダウンロードが開始されています

![メニューから LunaBox に送る](/assets/images/download-games/ja/download-menu@2x.webp)

送信される情報：

| フィールド       | 値                                          |
| ---------------- | ------------------------------------------- |
| ダウンロード URL | 署名付き期限付きダイレクトリンク            |
| ファイル名       | Shionlib 上の元のファイル名                 |
| 圧縮形式         | ファイル拡張子から自動判別                  |
| ファイルサイズ   | 検証用の正確なバイト数                      |
| チェックサム     | 整合性確認用 SHA-256 または BLAKE3 ハッシュ |
| ゲームタイトル   | ゲームの日本語タイトル                      |
| メタデータソース | Hikarinagi（ライブラリマッチング用）        |

## トラブルシューティング

**ダウンロードメニューで LunaBox を選んでも何も起きない**

まず、`lunabox://` プロトコルが正しく登録されているか確認してください：

- インストーラー版: 通常は自動登録されます。動作しない場合は上記の手順で再登録するか、再インストールで改善することがあります
- ポータブル版: 先に LunaBox を起動し、ファイルがあるディレクトリで `.\lunacli.exe --register-protocol` を実行してください

コマンド実行後は LunaBox を再起動してから、もう一度試してください。

**LunaBox にダウンロードタスクが表示されない**

- ブラウザまたは OS が `lunabox://` プロトコルをブロックしていないか確認してください
- LunaBox を開くかどうかの確認ダイアログを見落としていないか確認してください

**LunaBox を先に起動していなくてもダウンロードできるか**

はい。プロトコルが登録されていれば、Shionlib のダウンロードメニューで LunaBox を選ぶと LunaBox が自動で起動し、現在のダウンロード要求が渡されます。

**ロボットでないことの確認後にダウンロードが始まらない**

確認が済むと、ページは自動的にタスクを LunaBox に渡します。それでもダウンロードが開始されない場合は、ダウンロードメニューをもう一度開いて **LunaBox に送る** を選んでください。
