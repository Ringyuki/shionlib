## リソースを探す

任意のゲームのページを開くと、既定で表示される **ダウンロード** タブに、そのゲームで利用できるすべてのリソースが一覧表示されます。ページ上部の **ダウンロード** ボタンをクリックしても、この一覧に移動します。

リソースが多い場合は、一覧の上でプラットフォームによる絞り込みができます。

![ゲームページの「ダウンロード」タブとリソースカード](/assets/images/download-games/ja/resources@2x.webp)

> すべてのリソースはコミュニティのユーザーがアップロードしたものです。ファイルの安全性はご自身でご確認ください。

## リソースカードのラベルを読む

各リソースカードには、そのリソースの対応範囲を示すラベルがいくつか表示されます：

### プラットフォーム

**Windows**、**Android**、**iOS**、**PS Vita** など、そのリソースが対応する動作プラットフォームを示します。

1 枚のカードに複数のプラットフォームが表示されている場合は、その中のファイルに複数プラットフォーム向けの版が含まれているか、そのリソースが複数のプラットフォームで動作することを意味します。

### 言語

ゲームまたはパッチで使用されている言語を示します。次のものがあります：

| ラベル | 意味                             |
| ------ | -------------------------------- |
| 日本語 | 日本語（原版または日本語パッチ） |
| 簡体字 | 簡体字中国語への翻訳             |
| 繁体字 | 繁体字中国語への翻訳             |
| 英語   | 英語版または英語への翻訳         |

### エンジン（Android / iOS のみ）

プラットフォームが Android または iOS の場合にのみ表示されます。そのリソースで使用されているゲームエンジンを示し、適切なエミュレーターを選ぶ際の参考になります：

| ラベル           | エンジン                                           |
| ---------------- | -------------------------------------------------- |
| 吉里吉里（KRKR） | KiriKiri/KRKRZ エンジン                            |
| ONScripter       | ONScripter エンジン                                |
| Artemis          | Artemis Engine                                     |
| その他           | その他のエンジン。リソースの説明を参照してください |

![エンジンが表示されたリソースカード](/assets/images/download-games/ja/engine@2x.webp)

各エンジンに対応するエミュレーターの選び方については、[主要エンジンとエミュレーター対応表](/ja/docs/guides/common-vn-engines-and-emulators) を参照してください。

### 説明

一部のリソースには、アップロード者が記入した説明が付いています。そのリソースのバージョン情報、含まれる内容、特別な注意事項などが書かれているため、ダウンロード前に読むことをお勧めします。

## ファイル項目について

各リソースカードには 1 つ以上のファイル項目が含まれ、各項目には次の内容が表示されます：

- **ファイル名とサイズ** — 正しいファイルをダウンロードしているかを確認できます
- **チェックサム** — ダウンロード後にファイルの整合性を検証するために使用します
- **ファイルの状態** — 下記の説明を参照してください

分割アーカイブの各分割ファイルは順番に並べて表示されます。すべてをダウンロードしてからでないと展開できません。

リソースカードをクリックするとリソースページが開きます。その中の **内容** にはアーカイブ内のファイルが、**詳細情報** には各ファイルの完全なチェックサムとチェック結果が表示されます。

![リソースのページ。アーカイブ内のファイルが一覧表示される](/assets/images/download-games/ja/resource-page@2x.webp)

### ファイルの状態

ほとんどのファイルには何のマークも付いておらず、そのままダウンロードできます。次のマークが付いたファイルには注意が必要です：

| マーク               | 意味                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| ウイルスの可能性あり | ウイルススキャンで検出されたものの、管理者が審査のうえ許可したファイルで、ダウンロードできます |
| ブロック             | ウイルススキャンでウイルスが検出されたため、ダウンロードできません                             |

アップロードされたばかりのリソースは、チェックに合格してから公開されます。チェック中の状態（チェック中、分割ファイル待ち、保存中、審査待ちなど）は、アップロード者本人にのみ表示されます。詳しくは [ゲームファイルのアップロード方法](/ja/docs/guides/upload-game-files) を参照してください。

## ファイルをダウンロードする

ファイル項目の右側にある **ダウンロード** ボタンをクリックすると、ダウンロードが始まります。ダウンロードの前に、ページがロボットでないことの確認を自動で 1 回行います。通常は数秒で終わり、操作は一切必要ありません。確認が済んでから、ダウンロードリンクが発行されます。

> ダウンロードリンクには有効期限があり、ファイルが大きいほど有効期限は長くなります。リンクをコピーすると、具体的な時間が表示されます。有効期限内にダウンロードを完了してください。リンクが無効になった場合は、もう一度ダウンロードをクリックしてください。

### 通常のダウンロード

**ダウンロード** ボタンは、既定ではブラウザで直接ダウンロードします。ほとんどのユーザーに適しています。

### プッシュダウンロード

**ダウンロード** ボタンの右側にある矢印をクリックすると、**ほかのダウンロード方法** メニューが開き、現在利用できるすべての方法が一覧表示されます。いずれかを選ぶと、ダウンロードタスクを対応するクライアントに引き渡せます。

![「ほかのダウンロード方法」メニュー](/assets/images/download-games/ja/download-menu@2x.webp)

| プッシュ先       | 説明                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| **aria2**        | このパソコンまたはローカルネットワーク上で動作している aria2 ダウンロードマネージャーに送信           |
| **LunaBox**      | `lunabox://` プロトコルで LunaBox に引き渡してダウンロード・管理                                      |
| **ReinaManager** | `reinamanager://` プロトコルで ReinaManager に引き渡してダウンロード・管理                            |
| **PotatoVN**     | `potato-vn://` プロトコルで PotatoVN（PotatoDownload プラグインが必要）に引き渡してダウンロード・管理 |

メニューの **ダウンロードリンクをコピー** を使うと、リンクをほかのダウンロードツールに渡せます。

aria2 を使用する前に、**設定 → ダウンロード** で接続情報（RPC アドレス、RPC シークレット、保存先）を入力し、**接続をテスト** をクリックして接続できることを確認しておく必要があります。送信に失敗した場合は、ページに原因が表示され、ブラウザでのダウンロードに切り替えることもできます。メニュー下部の **ダウンロード設定** からも、これらの設定を直接開けます。

![ダウンロード設定の aria2 接続情報](/assets/images/account-settings/ja/aria2@2x.webp)

LunaBox、ReinaManager、PotatoVN の 3 項目は、**設定 → ダウンロード** でそれぞれオン・オフを切り替えられ、オフにするとメニューに表示されなくなります。同じページで、いずれかの方法を既定のダウンロード方法に設定することもでき、その後は **ダウンロード** ボタンをクリックするとその方法が直接使用されます。

ダウンロード設定は現在のブラウザにのみ保存され、アカウントには同期されません。

## ファイルハッシュを検証する

ダウンロードが完了したら、ファイルのハッシュ値を比較して整合性を確認することをお勧めします：

1. ファイル項目のチェックサムの横にあるコピーボタンをクリックし、完全なハッシュ値をコピーします
2. システムのツールまたはサードパーティのソフトウェアを使用して、ダウンロードしたファイルのハッシュ値を計算します
3. 2 つの値を比較し、完全に一致していればファイルは完全です

Shionlib は現在 **SHA-256** と **BLAKE3** の 2 種類のハッシュアルゴリズムに対応しており、使用しているアルゴリズムはチェックサムの前に明記されています。

## 誤検知のウイルスマーク

ファイル項目に **「ウイルスの可能性あり」** のマークが表示されている場合は、自動スキャンでウイルスの疑いのある特徴が検出されたものの、管理者が審査して**誤検知**と判断し、手動で許可したことを意味します。

マークの横の説明には、スキャンで検出されたウイルス名が参考として表示されます。

> ビジュアルノベル（特に KiriKiri などのエンジンを使用する作品）は、パッケージ方式が特殊なため、**ウイルス対策ソフトに誤検知されることがきわめて多くあります**。提供元が信頼できると確認できた場合は、安心してダウンロードできます。

## 変更履歴

リソースページを開いて **変更履歴** タブに切り替えると、そのリソースが公開されてからのすべての変更を確認できます。ファイルの差し替えとその理由、ファイルの追加や削除、名前の変更、プラットフォームや言語などの情報の編集が含まれます。

## リソースを報告する

リソースに問題（ウイルスが含まれている、内容がゲームと一致しない、ファイルをダウンロードできないなど）を見つけた場合は、リソースカードの **<Ellipsis />** メニューをクリックして **報告** を選び、報告の理由を記入してください。報告にはログインが必要です。悪意のある報告には相応の措置が取られます。
