## PotatoVN とは

[PotatoVN](https://potatovn.net) は、オープンソースの Windows 向けビジュアルノベル / 美少女ゲーム管理ツールです。ローカルゲームの自動検出、Bangumi や VNDB などからのゲーム情報取得、プレイ時間とステータスの記録、セーブデータのクラウド同期などに対応しています。

Shionlib からのプッシュは、PotatoVN の **PotatoDownload** プラグインが処理します。プラグインをインストールすると、PotatoVN は Shionlib から送信されたダウンロードタスクを受信し、以下を自動で行います：

- 📥 **ダウンロード** — マルチコネクションの分割ダウンロード、レジューム対応
- ✅ **検証** — ファイルサイズと SHA-256 / BLAKE3 ハッシュを照合
- 📦 **解凍** — 7Z、ZIP、RAR、TAR などの一般的なアーカイブ形式に対応
- 📚 **ライブラリ登録** — Bangumi / VNDB / Hikarinagi ID で既存のゲームとマッチング、なければ新規作成してメタデータを取得し、解凍先フォルダーをインストール先として登録

プラグインのソースコード：[luoyuxiaoxiao/PotatoDownload](https://github.com/luoyuxiaoxiao/PotatoDownload)

## PotatoVN と PotatoDownload プラグインのインストール

1. [potatovn.net](https://potatovn.net) から PotatoVN（1.10.2 以降）をインストールします。`potato-vn://` プロトコルはインストール時に PotatoVN 自身が登録するため、手動操作は不要です。
2. PotatoVN の**設定 → プラグイン**を開き、プラグインマーケットで **PotatoDownload** を検索してインストールします。
3. （任意）プラグイン設定を調整します：
   - **ダウンロードフォルダー**：空欄の場合はシステムドライブ直下の `Galgame` フォルダー（例：`C:\Galgame`）が使われます
   - **自動ダウンロード**：オンにするとタスク受信後すぐにダウンロードを開始してダウンロードパネルを表示、オフにすると先に確認ダイアログを表示します

> PotatoVN と PotatoDownload は **Windows** のみ対応です。

## Shionlib で PotatoVN を無効または有効にする

PotatoVN はデフォルトでダウンロードメニューに表示されます。

無効にする手順：

1. Shionlib の**設定**を開く
2. **ダウンロード**設定に入る
3. **ゲーム管理ツール** で **PotatoVN** を探す
4. そのスイッチをオフにする

オフにすると、ダウンロードメニューに PotatoVN が表示されなくなります。同じページで、**PotatoVN に送る** を既定のダウンロード方法に設定することもできます。設定後は、**ダウンロード** ボタンをクリックすると直接送信されます。

![ダウンロード設定のゲーム管理ツール](/assets/images/account-settings/ja/download@2x.webp)

> PotatoVN が受け取れるのは Bangumi ID のあるゲームのみです。ゲームに Bangumi ID がない場合、メニューのこの項目は選択できないため、ほかのダウンロード方法を使用してください。

## PotatoVN でダウンロードする

1. ゲームページを開き、**ダウンロード** タブでダウンロードしたいリソースとファイルを見つける
2. ファイルの右側にある **ダウンロード** ボタンの横の矢印をクリックして、**ほかのダウンロード方法** メニューを開く
3. メニューから **PotatoVN に送る** を選択する
4. ページがロボットでないことの確認を自動で行います
5. ブラウザが PotatoVN を開く許可を要求します
6. プラグインの自動ダウンロードがオフの場合は、PotatoVN でダウンロードを確認する

![メニューから PotatoVN に送る](/assets/images/download-games/ja/download-menu@2x.webp)

タスクを受信すると、PotatoDownload は以下を行います：

1. 設定されたダウンロードフォルダーにファイルをダウンロード（中断後の再開に対応）
2. ファイルサイズとハッシュ値を検証
3. ゲームフォルダーに解凍——アーカイブ内にトップレベルフォルダーが 1 つだけある場合はその名前、それ以外はアーカイブのファイル名を使用
4. Bangumi / VNDB / Hikarinagi ID でライブラリ内の既存ゲームとマッチング、なければ新規作成してメタデータを取得
5. 解凍先フォルダーをそのゲームのインストール先として登録

PotatoVN のサイドバーにある**ダウンロード**ボタンから、進行中のタスクと履歴をいつでも確認できます。

## 送信される情報

送信ごとに、PotatoVN は以下の情報を受信します：

| フィールド       | 内容                                                          |
| ---------------- | ------------------------------------------------------------- |
| ダウンロード URL | 署名付きの期限付きダイレクトリンク                            |
| ファイル名       | Shionlib 上の元のファイル名                                   |
| 圧縮形式         | 7Z、ZIP、RAR などのファイル形式                               |
| ファイルサイズ   | ファイルの正確なバイト数                                      |
| チェックサム     | SHA-256 または BLAKE3 ハッシュ                                |
| ゲームタイトル   | ゲームのタイトル                                              |
| resource_id      | 今回送信されたリソースを識別するための Shionlib 内リソース ID |
| Bangumi ID       | ゲームのマッチングおよびメタデータ取得用                      |
| VNDB ID          | オプション。ゲームのマッチングおよびメタデータ取得用          |
| Hikarinagi ID    | オプション。ゲームのマッチングおよびメタデータ取得用          |

## トラブルシューティング

### ダウンロードメニューで PotatoVN を選んでも何も起きない

以下を順に確認してください：

- PotatoVN がインストールされており、プラグインマーケットで PotatoDownload がインストール・有効化されているか
- ブラウザが `potato-vn://` プロトコルをブロックしていないか、「PotatoVN を開きますか」の確認ダイアログを閉じていないか
- PotatoVN のログ（`Logs\log.txt`）に `PotatoDownload` 関連のエラーがないか

### PotatoVN が起動した後、ホーム画面に移動してしまう

これは正常な動作です。PotatoVN はプロトコルによる起動時に必ずスタートページへ移動しますが、タスク自体はプラグインが受信しています。サイドバーの**ダウンロード**ボタンから確認してください。

### PotatoVN に「無効なプッシュリクエスト」と表示される

主な原因：

- 期限付きダウンロードリンクの有効期限切れ——Shionlib から再度ファイルを送信すると新しいリンクが生成されます
- ファイルがアーカイブではない——PotatoDownload は 7Z、ZIP、RAR、TAR などのアーカイブ形式のみ処理します

### PotatoVN を事前起動していなくても、直接送信できますか？

はい、可能です。

PotatoVN を選択すると、システムが自動的にアプリを起動してダウンロードタスクを渡します。

### ロボットでないことの確認後にダウンロードが始まらない

ダウンロードメニューを再度開き、**PotatoVN に送る** を選択してください。
