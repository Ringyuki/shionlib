設定ページはサイドバーの **設定** から開くことができ、プロフィール、セキュリティ、連携アカウント、ダウンロード、サイトの設定の 5 つの部分に分かれています。

## プロフィール

### ユーザー名を変更する

**プロフィール** ページのユーザー名の入力欄で変更します。最大 20 文字です。入力中に、そのユーザー名が使用できるかどうかが表示されます。変更後、**保存** をクリックしてください。

![設定のプロフィール](/assets/images/account-settings/ja/personal@2x.webp)

### アイコン、ヘッダー画像、自己紹介を変更する

アイコン、ヘッダー画像、自己紹介、ページの背景はプロフィールページで変更します。あなたのプロフィールページを開き、**プロフィールを編集** をクリックしてください。画像を選ぶと切り抜きツールが表示され、切り抜きが完了したあと **保存** をクリックすると反映されます。

## セキュリティ

![設定のセキュリティ](/assets/images/account-settings/ja/security@2x.webp)

### パスワードを変更する

**セキュリティ** ページでパスワードの欄の **変更** をクリックし、現在のパスワードと新しいパスワードを入力します。新しいパスワードの要件：

- 8 文字以上
- 大文字、小文字、および数字または記号をすべて含む

変更に成功すると、ほかの端末でのログイン状態は無効になり、再度ログインする必要があります。現在のパスワードを忘れた場合は、ログインダイアログで **パスワードを忘れた場合** をクリックし、メールに記載されたリンクからパスワードを再設定できます。

### メールアドレスを変更する

メールアドレスを変更するには、現在のメールアドレスと新しいメールアドレスをそれぞれ確認する必要があります：

1. 現在のメールアドレスに認証コードを送信し、入力します
2. 新しいメールアドレスを入力し、新しいメールアドレスに認証コードを送信して入力したうえで、変更を確定します

### パスキー（Passkey）

パスキーはパスワードを必要としないログイン方法で、端末の生体認証（指紋、顔認証）または端末のパスコードを使用して確認を行います。

**パスキーを追加する：**

1. **パスキーを追加** をクリックします。識別しやすいように、任意で名前（最大 128 文字）を入力できます
2. ブラウザに確認の要求が表示されるので、指示に従って確認を完了します
3. 確認に成功すると、パスキーは自動的に保存され、一覧に表示されます

**既存のパスキーを管理する：**

一覧の各パスキーには、名前、追加日時、最終使用日時が表示されます。削除ボタンをクリックすると該当するパスキーを削除でき、確認後に反映されます。

> お使いのブラウザまたは端末が WebAuthn に対応していない場合、この機能は使用できません。

## 連携アカウント

ほかのサービスとのアカウント連携を管理します：

- **Hikarinagi ID** — 連携すると Hikarinagi ID でログインできます。これが現在唯一のログイン方法である場合は連携を解除できず、先にパスワードを設定するかパスキーを追加する必要があります。
- **PotatoVN** — PotatoVN アカウントを連携します。入力したパスワードは PotatoVN にアクセス資格情報を要求するためだけに使用され、本サイトには保存されません。連携を解除しても、PotatoVN 上のデータは削除されません。

![設定の連携アカウント](/assets/images/account-settings/ja/connections@2x.webp)

## ダウンロード

既定のダウンロード方法を選び、プッシュダウンロードの送信先を設定します。

![既定のダウンロード方法とゲーム管理ツール](/assets/images/account-settings/ja/download@2x.webp)

**ゲーム管理ツール** の欄では、LunaBox、ReinaManager、PotatoVN をそれぞれオン・オフでき、オンにしたものはダウンロードメニューに表示されます。

**aria2** の欄では aria2 ダウンロードクライアントを設定し、このパソコンまたはローカルネットワーク上で動作している aria2 にゲームリソースを送信できるようにします：

| 項目             | 説明                                                              |
| ---------------- | ----------------------------------------------------------------- |
| RPC アドレス     | aria2 の JSON-RPC アドレス（例：`http://127.0.0.1:6800/jsonrpc`） |
| RPC シークレット | aria2 の RPC Secret（設定している場合）                           |
| 保存先           | 空欄の場合は aria2 の既定のディレクトリを使用                     |

![aria2 の接続情報](/assets/images/account-settings/ja/aria2@2x.webp)

使用する前に、aria2 で RPC を有効にし、本サイトからのクロスオリジン要求を許可しておく必要があります。入力後、**接続をテスト** をクリックして設定が正しいかどうかを確認できます。

ダウンロード設定はローカルのブラウザにのみ保存され、アカウントには同期されません。

## サイトの設定

![設定のサイト設定](/assets/images/account-settings/ja/site@2x.webp)

### 表示言語

表示言語（简体中文、English、日本語）を選ぶと、ページはすぐに選択した言語に切り替わり、あなたに送信されるメールにもこの言語が使用されます。

### テーマ

ライト、ダーク、システムに合わせるのいずれかを選びます。この設定はローカルのブラウザにのみ保存されます。

### 成人向けコンテンツ

成人向けコンテンツを含むゲームと画像の表示方法を制御します。3 つの選択肢があります：

- **非表示** — 成人向けコンテンツを含むゲームと画像を表示しません
- **マスク** — ゲームは表示し、画像は既定で隠して、クリックすると表示します
- **表示** — すべての内容をそのまま表示します

変更はすぐに反映されます。ログインしていない場合、成人向けコンテンツを含むゲームと画像は表示されません。

### その他

- **リソースのあるゲームのみ** — ゲームライブラリと検索の既定の設定として使用され、閲覧のたびに一時的に変更できます
- **他のユーザーのページ背景を表示する** — オフにすると、他のユーザーのプロフィールページにはサイトの標準の背景が使用されます
