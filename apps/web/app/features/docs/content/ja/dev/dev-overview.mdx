## リポジトリ

[Shionlib](https://github.com/Ringyuki/shionlib)

リポジトリは monorepo です。`apps/web` は Web クライアント、`apps/api` はバックエンド、`apps/download-worker` と `apps/og` はエッジで動作するダウンロードプロキシと共有用画像サービスです。

## 技術スタック

### フロントエンド

**コアスタック**：React Router 8, React 19, TypeScript, Vite, Tailwind CSS, hina-ui, use-intl, valibot, MDX, Tiptap, pnpm

- フレームワーク：`React Router 8`（フレームワークモード、サーバーサイドレンダリング）
- 言語とランタイム：`React 19` + `TypeScript`
- スタイルと UI：`Tailwind CSS 4`、`@hina-ui/react`、`Lucide`
- 国際化：`use-intl`（ルーティングベースの多言語対応とロケールのネゴシエーション）
- API の型：バックエンドの OpenAPI ドキュメントから `openapi-typescript` で生成
- フォームとバリデーション：`valibot`
- コンテンツ/ドキュメント：MDX（`@mdx-js/rollup`）、Frontmatter は `remark-frontmatter` で解析
- リッチテキスト編集：`Tiptap`
- テスト：`Vitest`、`Playwright`
- デプロイ：Docker イメージ、Dokploy でデプロイ

### バックエンド

**コアスタック**：Go, chi, Huma, ent, PostgreSQL, Redis, River, AWS S3 SDK, Backblaze B2 (S3-compatible), ClamAV, 7-Zip, OpenTelemetry

- 言語：`Go`
- HTTP：`chi` ルーター + `Huma`（コードから OpenAPI ドキュメントを生成）
- データレイヤー：`ent`、`PostgreSQL`。マイグレーションは `Atlas` で生成し、`golang-migrate` で実行
- キャッシュとレート制限：`Redis`
- ジョブキュー：`River`（PostgreSQL ベース）
- ストレージとアップロード：`AWS S3 SDK`、`Backblaze B2`（ゲームファイル）、S3 互換ストレージ（画像）
- ファイルチェック：`7-Zip`（整合性テストと内容の読み取り）、`ClamAV`（ウイルススキャン）
- 認証：`JWT`、パスキー（WebAuthn）、Hikarinagi ID（OIDC）
- 国際化：Cookie / Accept-Language から解決する多言語のエラーメッセージと通知
- 可観測性：`OpenTelemetry`
- デプロイ：Docker イメージ、Dokploy でデプロイ
