设置页面可以从侧栏的 **设置** 进入，分为个人资料、账号安全、关联账号、下载和站点偏好五个部分。

## 个人资料

### 修改用户名

在 **个人资料** 页面的用户名输入框中修改，最多 20 个字符。输入时会提示该用户名是否可用，修改后点击 **保存**。

![设置中的个人资料](/assets/images/account-settings/zh/personal@2x.webp)

### 修改头像、头图和简介

头像、头图、简介和页面背景在个人主页上修改。打开你的个人主页，点击 **编辑资料**；选择图片后会弹出裁剪工具，裁剪完成后点击 **保存** 生效。

## 账号安全

![设置中的账号安全](/assets/images/account-settings/zh/security@2x.webp)

### 更改密码

在 **账号安全** 页面点击密码一栏的 **修改**，填写当前密码和新密码。新密码要求：

- 至少 8 个字符
- 同时包含大写字母、小写字母，以及数字或符号

修改成功后，其他设备上的登录状态将失效，需重新登录。如果忘记当前密码，可以在登录窗口点击 **忘记密码？**，通过邮件中的链接重置密码。

### 更改邮箱

更改邮箱需要分别验证当前邮箱和新邮箱：

1. 向当前邮箱发送验证码并填入
2. 填写新邮箱地址，向新邮箱发送验证码并填入，确认修改

### 通行密钥（Passkey）

通行密钥是一种无需密码的登录方式，使用设备的生物识别（指纹、面部识别）或设备密码完成验证。

**添加通行密钥：**

1. 点击 **添加通行密钥**，可选填一个名称（最多 128 字符）便于识别
2. 浏览器弹出验证请求，按提示完成验证
3. 验证成功后，通行密钥自动保存并出现在列表中

**管理已有通行密钥：**

列表中每条通行密钥会显示名称、添加时间，以及最后使用时间。点击删除按钮可以移除对应通行密钥，确认后生效。

> 如果你的浏览器或设备不支持 WebAuthn，该功能将不可用。

## 关联账号

管理与其他服务的账号关联：

- **Hikarinagi ID** — 关联后可以使用 Hikarinagi ID 登录。它是当前唯一的登录方式时不能解除关联，需要先设置密码或添加通行密钥。
- **PotatoVN** — 关联你的 PotatoVN 账号。输入的密码仅用于向 PotatoVN 请求访问凭证，本站不会保存；解除关联不会删除你在 PotatoVN 上的任何数据。

![设置中的关联账号](/assets/images/account-settings/zh/connections@2x.webp)

## 下载

选择默认的下载方式，并配置推送下载的目标。

![默认下载方式与游戏管理器](/assets/images/account-settings/zh/download@2x.webp)

**游戏管理器** 一栏可以分别开关 LunaBox、ReinaManager 与 PotatoVN，开启后它们会出现在下载菜单中。

**aria2** 一栏用于配置 aria2 下载客户端，把游戏资源推送到本机或局域网中运行的 aria2：

| 字段     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| RPC 地址 | aria2 的 JSON-RPC 地址，如 `http://127.0.0.1:6800/jsonrpc` |
| RPC 密钥 | aria2 的 RPC Secret（如有设置）                            |
| 保存目录 | 留空则使用 aria2 默认目录                                  |

![aria2 的连接信息](/assets/images/account-settings/zh/aria2@2x.webp)

使用前需要先在 aria2 中启用 RPC，并允许来自本站的跨域请求。填写完成后，可以点击 **测试连接** 验证配置是否正确。

下载设置仅保存在本地浏览器中，不同步到账号。

## 站点偏好

![设置中的站点偏好](/assets/images/account-settings/zh/site@2x.webp)

### 界面语言

选择界面语言（简体中文、English、日本語），页面会立即切换至所选语言，发送给你的邮件也会使用这种语言。

### 主题

选择浅色、深色或跟随系统。此设置仅保存在本地浏览器中。

### 成人内容

控制带有成人内容的游戏和图片的显示方式，有三个选项：

- **隐藏** — 不显示带有成人内容的游戏和图片
- **遮罩** — 显示游戏，图片默认遮住，点击后查看
- **显示** — 直接显示全部内容

修改后立即生效。未登录时，带有成人内容的游戏和图片不会显示。

### 其他

- **仅显示有资源的游戏** — 作为游戏库和搜索的默认设置，可以在每次浏览时临时更改
- **显示其他用户的页面背景** — 关闭后，其他用户的个人主页使用站点的默认背景
