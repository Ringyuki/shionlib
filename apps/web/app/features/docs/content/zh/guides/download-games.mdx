## 找到资源

打开任意游戏的页面，默认显示的 **资源** 标签列出了该游戏的所有可用资源。点击页面上方的 **下载** 按钮，也会跳到这份列表。

资源较多时，列表上方可以按平台筛选。

![游戏页面的「资源」标签和资源卡片](/assets/images/download-games/zh/resources@2x.webp)

> 所有资源均由社区用户上传，请自行鉴别文件安全性。

## 读懂资源卡片上的标注

每张资源卡片上都会显示若干标签，用于描述该资源的适用范围：

### 平台

标注该资源适用的运行平台，例如 **Windows**、**Android**、**iOS**、**PS Vita** 等。

一张卡片可能同时标注多个平台，代表其中的文件包含多平台版本，或该资源可跨平台运行。

### 语言

标注游戏/补丁所使用的语言，包括：

| 标注 | 含义                   |
| ---- | ---------------------- |
| 日文 | 日语（原版或日语补丁） |
| 简中 | 简体中文汉化           |
| 繁中 | 繁体中文汉化           |
| 英文 | 英语版本或英语翻译     |

### 引擎（仅 Android / iOS）

仅在平台为 Android 或 iOS 时显示，标注该资源所使用的游戏引擎，用于帮助你选择合适的模拟器：

| 标注             | 引擎                     |
| ---------------- | ------------------------ |
| KiriKiri（KRKR） | KiriKiri/KRKRZ 引擎      |
| ONScripter       | ONScripter 引擎          |
| Artemis          | Artemis Engine           |
| 其他             | 其他引擎，请参考资源说明 |

![标注了引擎的资源卡片](/assets/images/download-games/zh/engine@2x.webp)

关于各引擎对应的模拟器选择，请参阅 [常见引擎与模拟器对照](/zh/docs/guides/common-vn-engines-and-emulators)。

### 说明

部分资源会附带上传者填写的说明，介绍该资源的版本信息、包含内容或特殊注意事项，建议下载前阅读。

## 文件条目说明

每张资源卡片下可能包含一个或多个文件条目，每个条目显示：

- **文件名与大小** — 确认你下载的是正确的文件
- **校验值** — 用于下载后校验文件完整性
- **文件状态** — 见下方说明

分卷压缩包的各个分卷会按顺序排在一起，需要全部下载后才能解压。

点击资源卡片可以打开资源页面，其中的 **内容** 列出了压缩包里的文件，**详细信息** 列出了每个文件的完整校验值和检查结果。

![资源页面，列出压缩包里的文件](/assets/images/download-games/zh/resource-page@2x.webp)

### 文件状态

大多数文件没有任何标记，可以直接下载。带有下列标记的文件需要留意：

| 标记         | 含义                                             |
| ------------ | ------------------------------------------------ |
| 可能存在病毒 | 病毒扫描曾标记该文件，管理员复核后放行，可以下载 |
| 已拦截       | 病毒扫描检测到病毒，文件无法下载                 |

刚上传的资源需要先通过检查才会发布。检查期间的状态（检查中、等待分卷、保存中、等待复核等）只有上传者本人能看到，详见 [如何上传游戏文件](/zh/docs/guides/upload-game-files)。

## 下载文件

点击文件条目右侧的 **下载** 按钮开始下载。下载前，页面会自动进行一次人机验证，通常只需几秒，不需要任何操作；验证通过后才会生成下载链接。

> 下载链接有时效限制，文件越大有效期越长，复制链接时会显示具体的时长。请在有效期内完成下载；链接失效后重新点击下载即可。

### 普通下载

**下载** 按钮默认通过浏览器直接下载，适合大多数用户。

### 推送下载

点击 **下载** 按钮右侧的箭头，会打开 **其他下载方式** 菜单，列出当前可用的所有方式。选择其中一项，即可把下载任务交给对应的客户端处理。

![「其他下载方式」菜单](/assets/images/download-games/zh/download-menu@2x.webp)

| 推送目标         | 说明                                                                          |
| ---------------- | ----------------------------------------------------------------------------- |
| **aria2**        | 推送到本机或局域网中运行的 aria2 下载管理器                                   |
| **LunaBox**      | 通过 `lunabox://` 协议交给 LunaBox 下载并管理                                 |
| **ReinaManager** | 通过 `reinamanager://` 协议交给 ReinaManager 下载并管理                       |
| **PotatoVN**     | 通过 `potato-vn://` 协议交给 PotatoVN（需安装 PotatoDownload 插件）下载并管理 |

菜单中的 **复制下载链接** 可以把链接交给其他下载工具。

使用 aria2 前，需先在 **设置 → 下载** 中填写连接信息（RPC 地址、RPC 密钥、保存目录），并点击 **测试连接** 确认可以连通。推送失败时，页面会提示原因，并可以改用浏览器下载；菜单底部的 **下载设置** 也可以直接打开这些设置。

![下载设置中的 aria2 连接信息](/assets/images/account-settings/zh/aria2@2x.webp)

LunaBox、ReinaManager 与 PotatoVN 三项可以在 **设置 → 下载** 中分别开关，关闭后就不会出现在菜单里。在同一页面还可以把任意一种方式设为默认的下载方式，此后点击 **下载** 按钮就会直接使用它。

下载设置只保存在当前浏览器中，不随账号同步。

## 校验文件哈希

下载完成后，建议对比文件的哈希值以确认文件完整性：

1. 点击文件条目中校验值旁的复制按钮，复制完整的哈希值
2. 使用系统工具或第三方软件计算下载文件的哈希值
3. 对比两个值，完全一致则说明文件完整

Shionlib 目前支持 **SHA-256** 和 **BLAKE3** 两种哈希算法，校验值前会明确标注使用的算法。

## 误报病毒标记

如果文件条目显示 **「可能存在病毒」** 标记，说明自动扫描流程曾检测到疑似病毒特征，但管理员审核后认定为**误报**并手动放行。

标记旁的说明中会显示扫描检测到的病毒名称，供你参考。

> 视觉小说游戏（尤其是使用 KiriKiri 等引擎的作品）因为打包方式特殊，**极易被杀毒软件误报**。在确认来源可信的情况下，可以放心下载。

## 变更历史

打开资源页面，切换到 **变更历史** 标签，可以查看该资源发布以来的全部改动，包括替换文件及其原因、添加或移除文件、重命名，以及平台、语言等信息的修改。

## 举报资源

如果你发现某个资源存在问题（如含有病毒、内容与游戏不符、文件无法下载等），可以点击资源卡片上的 **<Ellipsis />** 菜单，选择 **举报**，并填写举报原因。举报需要登录，恶意举报会受到相应处置。
