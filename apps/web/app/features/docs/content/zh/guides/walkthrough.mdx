## 查看攻略

在游戏条目页面，点击顶部的 **攻略** 标签，可以查看该游戏下所有已发布的攻略。

每份攻略会显示作者、语言、线路数量和更新时间。选择一份攻略后，可以阅读它的说明，并在各条线路之间切换；线路中的每一步、存档与读档的位置都会依次列出。

## 编写攻略

在攻略标签页，点击 **写攻略** 按钮（需要登录），进入编写页面。每位用户在每个游戏下可以编写一份攻略；已经写过的话，按钮会变为 **编辑我的攻略**。

一份攻略包含两个部分：

- **说明** — 选填，用于介绍推荐的攻略顺序、注意事项等，支持加粗、剧透和链接
- **线路** — 一份攻略可以包含多条线路，每条线路有以下内容：
  - **线路名称** — 必填
  - **角色** — 选填，从该游戏的角色中选择这条线路对应的角色
  - **开放条件** — 选填，可以指定须先通关的线路，或填写其他条件
  - **步骤** — 每行一步，至少填写一步
  - **结局** — 选填

步骤中可以使用以下写法：

| 写法                                          | 含义                            |
| --------------------------------------------- | ------------------------------- |
| `存档 1`                                      | 在这里存档到 1 号位             |
| `读档 1`                                      | 读取 1 号位的存档               |
| 以 `#` 或 `※` 开头的行，以及以 `END` 结尾的行 | 备注                            |
| `选项文字 \| 附注`                            | `\|` 之后的文字作为这一步的附注 |

步骤旁边的 **预览** 会随着输入实时显示攻略的实际效果；在较窄的屏幕上，通过 **编辑** 和 **预览** 切换查看。拖动线路可以调整顺序。

![编写攻略：左侧填写步骤，右侧显示预览](/assets/images/walkthrough/zh/write@2x.webp)

编写完成后，可以选择 **保存草稿** 或 **发布**。

## 草稿与发布

| 操作     | 状态   | 可见性     |
| -------- | ------ | ---------- |
| 保存草稿 | 草稿   | 仅自己可见 |
| 发布     | 已发布 | 所有人可见 |

草稿状态的攻略会显示 **草稿** 标记，仅对你可见。你可以随时回来继续编辑并发布；已发布的攻略也可以通过 **转为草稿** 收回。

## 编辑攻略

攻略的作者可以随时编辑自己的攻略：在游戏的攻略标签页点击 **编辑我的攻略**，或者在个人主页的攻略列表中打开它。

编辑后同样可以选择保存为草稿或重新发布，攻略的更新时间会随之变化。

## 审核

点击 **发布** 后，攻略不会立刻对外可见，而是先进入 **审核中** 状态，由系统自动完成内容审核。

审核通过后，攻略状态会自动变为已发布，对所有人可见。若审核未通过，攻略将显示 **未通过审核** 并继续保持隐藏，作者会收到一条系统消息，说明未通过的原因。

> 正常情况下，审核会在发布后较短时间内完成。如果长时间处于"审核中"状态，可以联系管理员。

## 删除攻略

在编写页面的 **<Ellipsis />** 菜单中选择 **删除攻略**，确认后永久删除该攻略，此操作无法撤销。

## 在个人主页查看攻略

访问个人主页，切换到 **攻略** 标签，可以看到你编写的所有攻略，每条记录会显示对应的游戏、线路数量和更新时间，草稿和审核中的攻略带有状态标记。

访问他人主页的攻略页面时，只能看到对方已发布的攻略。
