## Shionlib 的大文件上传系统介绍

### 为什么需要设计一套大文件上传系统？

Shionlib 的目标之一是创建和维护一个完整、可控的全年代 视觉小说/Galgame 档案库，达成这个目标绝非易事，以我们的经验来看，只有**社区驱动**的模式才能做到这一点。

因此，我们设计了一套上传系统，向所有用户开放大文件上传权限。

### 上传系统的工作流程

你选择本地文件后，浏览器会把文件切成分片（每片约 50 MB）逐个发送到 Shionlib 服务器，并在上传的同时计算每个分片和整个文件的 SHA-256 哈希值。

全部分片上传完成后，服务器会再次计算整个文件的 SHA-256 哈希值，并与浏览器计算的哈希值进行对比，如果一致，则标记为上传成功。

随后，Shionlib 服务器会对上传完成的文件进行检查：压缩包和分卷压缩包会用 7-Zip 完整测试一遍，确认文件完整、没有损坏、没有被加密；压缩包内的可执行文件还会经过病毒扫描。

最后，通过检查的文件会被保存到 Shionlib 的存储桶。一个资源的全部文件保存完成后，资源自动发布，你会收到一条站内消息。

### 挑战

显而易见的，我们必须非常谨慎地设计整个系统，如果有任何人试图以各种方式破坏系统，后果都将是难以承受的。

- 恶意上传大量巨大文件。这会占用超出预期的大量存储空间，我们可能会因此需要支付高额的储存费用
- 恶意上传包含恶意程序的文件。尽管在整个流程中，我们不会执行文件，但依旧可能会对下载此文件的用户造成威胁

为了保障整个系统可以正常、可持续地运行，我们为每位上传者设置了**存储空间**上限，并按已发布资源的数量分为三档：

| 档位       | 条件                             | 存储空间 |
| ---------- | -------------------------------- | -------- |
| 新上传者   | 无                               | 50 GB    |
| 普通上传者 | 已发布 3 个资源                  | 300 GB   |
| 可信上传者 | 已发布 30 个资源，或由管理员授予 | 2 TB     |

已存储的文件和正在上传的文件合计不能超过存储空间的上限。单个文件不能超过 30 GB，同时进行中的上传合计也不能超过 30 GB。删除资源或文件后，它占用的空间会立即释放。当前的档位和已使用的空间显示在 **我的上传** 页面。

如果你需要更多的空间，可以向管理员申请成为可信上传者。

**需要注意的是，以下任何一种情况都属于违规，系统会在一段时间内降低你的档位，甚至封禁你的账号：**

- 你上传的文件被管理员确认包含恶意程序
- 其他用户举报你上传的资源，且管理员核实举报成立

## 上传文件

### 格式以及文件命名规范

建议将文件打包为 zip/rar/7z 压缩包后上传，压缩包**不能设置密码**。

一个资源可以包含多个文件。分卷压缩包可以直接上传，不需要重新打包：请把同一组分卷放在同一个资源里，并保持原有的文件名（如 `.part1.rar`、`.r00`、`.7z.001`、`.z01`），系统会按文件名识别分卷，在全部分卷上传后一起检查。

文件的名称不必手动整理。资源默认使用**规范文件名**：发布时，站点按游戏条目和资源信息为文件重新命名，格式为：

- `[发售日][品牌] 原名 译名 发行版本 [翻译][补丁版本] (形态).扩展名`

发售日、品牌和标题取自游戏条目，译名只用于中文资源，其余各项取自资源信息，没有内容的部分省略。括号内为形态：光盘映像为其格式（如 `iso+mds`，由文件检查得出），安装程序和免安装均为 `files`。例如：

- `[160729][ゆずソフト] 千恋＊万花 [官方中文] (files).part1.rar`

规范文件名只用于资源的第一个文件，分卷则为同一组的全部分卷。如果希望保留上传时的文件名，可以关闭 **使用规范文件名**。

语言、翻译、汉化组、补丁版本等信息请填写在资源信息中（见下文），不必写进文件名。

### 开始上传

点击侧栏顶部的 **上传资源** 按钮，或游戏页面中的 **上传资源** 按钮，打开上传页面。

在上传页面选择游戏和要上传的文件，然后填写资源信息。选择文件后，页面会从文件名中识别翻译、汉化组、补丁版本、发行版本和形态，预先填入尚未填写的项，请逐项核对。页面上会显示你的存储空间，以及这次选择的文件将占用多少。

资源信息包括：

- **平台**、**语言** — 必填，可多选
- **引擎** — 平台包含 Android 或 iOS 时必填，即运行该资源所用的引擎
- **翻译** — 语言中有日文以外的语言时必填：无、官方翻译、汉化组或机器翻译。选择汉化组时须填写汉化组的名称，最多 6 个，输入时会列出站内已有的汉化组；选择汉化组或机器翻译时，还可以填写补丁版本和发布页
- **发行版本** — 下载版、光盘版或 Steam 版，以及版本名称（如初回限定版），选填
- **形态** — 必填：光盘映像、安装程序或免安装。检查发现压缩包内有光盘映像时，形态会自动改为光盘映像
- **附带内容** — 全CG存档、特典，选填
- **说明** — 对资源的补充说明，选填，最多 255 字，可以使用粗体、剧透和链接
- **文件名** — 资源发布后的文件名，见上文的规范文件名

![选择游戏和文件，填写资源信息](/assets/images/upload-game-files/zh/upload-page@2x.webp)

点击 **开始上传** 后，页面会转到 **我的上传**，你可以在这里查看每个文件的上传进度。上传过程中可以继续浏览本站的其他页面，但请不要关闭所有 Shionlib 页面，直到上传完成。

![在「我的上传」中查看上传进度](/assets/images/upload-game-files/zh/uploading@2x.webp)

你可以随时点击 **暂停上传** 按钮来暂停上传，稍后点击 **继续上传** 按钮即可继续上传。

我们在设计时考虑到了上传中断的情况，并提供了断点续传。如果页面被关闭或刷新，回到 **我的上传**，此时会显示尚未完成的上传，点击 **重新选择文件** 按钮，选择相同文件即可从中断处继续上传。超过 24 小时没有进展的上传会过期。

![重新选择文件以继续上传](/assets/images/upload-game-files/zh/resume-upload@2x.webp)

### 检查与发布

文件上传完成后，系统会开始对文件进行检查和保存。你可以在 **我的上传** 的 **处理中** 查看进度，文件旁会显示它当前的状态：

| 状态       | 含义                                                   |
| ---------- | ------------------------------------------------------ |
| 检查中     | 正在检查文件的完整性和安全性                           |
| 等待分卷   | 这组分卷还不完整，补齐后才会检查                       |
| 保存中     | 文件已通过检查，正在保存                               |
| 等待复核   | 病毒扫描发现可疑内容，正在等待管理员复核               |
| 检查未完成 | 系统未能完成检查，已转交管理员处理，暂时无需操作       |
| 未通过检查 | 文件不完整、已损坏、设置了密码或含有有害内容，将被清除 |

分卷不完整时，页面会列出缺少的文件和补传的期限，请在期限内通过 **添加文件** 补传，逾期这组文件将被移除。

资源在发布之前仅你自己可见。全部文件保存完成后，资源会自动发布，并出现在 **我的上传** 的 **已发布** 中。
