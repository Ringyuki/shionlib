## Saving a game

On a game entry page, click the **Favorite** button to open the list of your favorite lists. It shows all your lists; click a list to add the game to it, and click it again to remove the game from it.

![Choosing lists on a game page](/assets/images/favorites/en/favorite-dialog@2x.webp)

A game can be added to several lists at the same time.

## Default list

Every user has a **Default list** created automatically by the system. It cannot be deleted and its name cannot be changed, but you can edit its description and visibility.

## Creating custom lists

At the bottom of the favorites popup, click the **New list** button and fill in the following:

- **Name** — the name of the list (required)
- **Description** — a supplementary description of the list (optional)
- **Only visible to me** — when checked, nobody else can see this list (unchecked by default, meaning public)

After the list is created, the current game is added to the new list directly.

## Private lists

A list set to be visible only to you carries a **Private** mark and is not shown when other users visit your profile. Only you, after signing in, can see and access its contents.

You can switch a list between public and private at any time by editing it.

## Managing lists

**Favorites** in the sidebar opens the **My favorites** page, which lists all your lists, including the private ones. After you switch to a list, the top of the page shows its name, description and number of games, and offers the following actions:

![The page of your favorites](/assets/images/favorites/en/my-favorites@2x.webp)

- **Edit list** — change the list's name (the name of the default list cannot be changed), description and visibility
- **Delete list** — permanently delete the list and all the favorites in it; the default list cannot be deleted

Deleting a list does not affect the games themselves; only the favorites are removed.

For each game in a list, you can also use the **<Ellipsis />** menu to **Edit note** or **Remove from list**.

## Viewing others' favorites

Visit another user's profile and click the **Favorites** tab to view their public lists. Private lists are not visible to others.
