## Before You Start

This guide answers one practical question: after downloading a game package, which emulator/runtime should you use?

Two core rules:

- If a native build is available (for example, a Windows executable), prefer native first.
- If you need an emulator, prioritize projects with public source code and active maintenance.

## Quick Mapping

Android / iOS resources are labeled with an **Engine** tag.  
Current tag values are: **KiriKiri (KRKR)** / **ONScripter** / **Artemis** / **Other**.

This tag describes the engine type of the package; it is not always a single mandatory app name.

![The engine named on a resource card](/assets/images/download-games/en/engine@2x.webp)

- KiriKiri (KRKR) / ONScripter / Artemis (Android): start with the latest Tyranor package

- KiriKiri (KRKR) / ONScripter (iOS): install the corresponding emulators directly from the App Store.
- Other: follow the resource's note for the runtime method.

Recent Tyranor builds can cover common KRKR, ONS, and Artemis scenarios. If a release page requires a specific patch or runtime method, follow that release note first.

## Platform Recommendations

### Windows

- Prefer native launchers first.
- If a release explicitly requires a specific environment/patch, follow the release instructions.

### Android

- Check the resource card's Engine tag first (KiriKiri (KRKR) / ONScripter / Artemis / Other).
- KiriKiri (KRKR) / ONScripter / Artemis: use Tyranor 2.3.3 first.
- Other, or compatibility issues: switch according to the resource's note.

### iOS

- Tyranor is currently not available on iOS.
- iOS users should install KRKR / ONS emulators from the App Store based on the engine tag.
- For Artemis or Other tags, prioritize the resource's note to confirm a workable method.

## FAQ

### The game launches but shows black screen / crashes

Try another emulator version for the same engine first, then check whether the resource's note requires a specific patch or a specific emulator version.

### I cannot identify the engine

Check the resource's note first. If it is not specified, inspect the folder structure and launcher filename. If still unclear, ask the uploader in comments.
