## 什么是 LunaBox

[LunaBox](https://box.lunarain.site) 是一款快速、美观、功能丰富的轻量视觉小说管理工具。除下载功能外，它还能帮你整理游戏库、记录游玩时间，并通过内置 AI 助手分析你的游玩习惯。

主要功能：

- **游戏管理** — 自定义分类与灵活的元数据管理，整理你的游戏库
- **游玩时长统计** — 自动记录游玩时长，生成多维度统计图表
- **AI 分析** — 内置 AI 助手，分析游玩习惯并生成趣味报告
- **云备份** — 支持 S3 和 OneDrive，安全同步与备份数据
- **下载集成** — 自动解压、校验文件完整性、支持断点续传

## 安装 LunaBox

从官方网站下载并安装 LunaBox：**https://box.lunarain.site**

目前提供两种 Windows 版本：

- **安装版（setup）**：推荐普通用户使用。安装过程中会自动尝试注册 `lunabox://` 协议，下载按钮通常开箱即用。数据默认保存在 `%APPDATA%\LunaBox`。
- **便携版（portable）**：解压即用，但首次使用前通常需要手动注册 `lunabox://` 协议。数据默认保存在程序目录。

如果你之后更换了便携版目录、重装系统，或发现安装版无法正常通过协议启动 LunaBox，也可以重新执行下面的命令。

```powershell
# 切换到 lunacli 所在目录，执行注册协议命令
.\lunacli.exe --register-protocol

# 将 lunacli 添加到系统环境变量后，可以直接使用，安装版会自动处理环境变量注册
lunacli --register-protocol
```

参照[LunaBox文档](https://box.lunarain.site/features/cli.html)

> LunaBox 目前仅支持 **Windows**。

## 在 Shionlib 中禁用或启用 LunaBox

LunaBox 默认出现在推送菜单中。禁用方式：

1. 打开**设置** → **下载**（或前往 `/user/settings/download`）
2. 找到 **LunaBox** 设置项
3. 关闭**在推送菜单中显示 LunaBox**

禁用后，下载面板的推送菜单中将不再出现 LunaBox 一项。

## 使用 LunaBox 下载

1. 在任意游戏页面点击**下载**，打开下载面板
2. 找到你想要的资源和文件
3. 点击文件行右侧的**纸飞机图标**按钮，打开推送菜单
4. 在菜单中选择 **LunaBox**，将下载任务推送过去
5. 如果需要 Turnstile 验证，在弹出窗口中完成验证——验证通过后任务会自动发送给 LunaBox
6. 切换到 LunaBox，下载即已开始

每次推送时，LunaBox 会收到以下信息：

| 字段       | 值                                     |
| ---------- | -------------------------------------- |
| 下载链接   | 带签名的限时直链                       |
| 文件名     | Shionlib 中的原始文件名                |
| 压缩格式   | 根据文件扩展名自动识别                 |
| 文件大小   | 精确字节数，用于校验                   |
| 校验值     | SHA-256 或 BLAKE3 哈希，用于完整性校验 |
| 游戏标题   | 游戏的日语标题                         |
| 元数据来源 | Bangumi（用于游戏库匹配）              |

## 常见问题

**在推送菜单中选择 LunaBox 后没有反应**

优先检查是否已正确注册 `lunabox://` 协议：

- 安装版：一般会自动注册；如果失效，参照上文重新注册协议，或者重新安装通常即可修复
- 便携版：请先启动 LunaBox，再在文件所在目录执行 `.\lunacli.exe --register-protocol`

执行命令后关闭后重新启动再试。

**下载任务没有出现在 LunaBox 中**

- 检查浏览器或系统是否拦截了 `lunabox://` 协议
- 检查是否有“是否打开 LunaBox”的确认弹窗被忽略

**LunaBox 没有提前打开，能直接下载吗**

可以。只要协议已注册，在 Shionlib 的推送菜单中选择 LunaBox 后，协议会自动启动 LunaBox，并把当前下载请求带过去。

**Turnstile 验证后下载没有开始**

Turnstile 弹窗在验证通过后会自动关闭。如果下载仍未开始，再次打开推送菜单选择 LunaBox 即可——本次会话中签名链接已缓存，无需再次验证。
