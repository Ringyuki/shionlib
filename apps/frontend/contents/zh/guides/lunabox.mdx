## 什么是 LunaBox

[LunaBox](https://box.lunarain.site) 是一款快速、美观、功能丰富的轻量视觉小说管理工具。除下载功能外，它还能帮你整理游戏库、记录游玩时间，并通过内置 AI 助手分析你的游玩习惯。

主要功能：

- **游戏管理** — 自定义分类与灵活的元数据管理，整理你的游戏库
- **游玩时长统计** — 自动记录游玩时长，生成多维度统计图表
- **AI 分析** — 内置 AI 助手，分析游玩习惯并生成趣味报告
- **云备份** — 支持 S3 和 OneDrive，安全同步与备份数据
- **下载集成** — 自动解压、校验文件完整性、支持断点续传

## 安装 LunaBox

从官方网站下载并安装 LunaBox：**https://box.lunarain.site**

LunaBox 在安装过程中会注册自定义协议处理程序（`lunabox://`）。Shionlib 通过此协议将下载任务直接发送到 LunaBox。

> LunaBox 目前仅支持 **Windows**。移动设备上不会显示 LunaBox 按钮。

## 在 Shionlib 中禁用或启用 LunaBox 按钮

LunaBox 下载按钮默认显示。禁用方式：

1. 打开**设置** → **下载**（或前往 `/user/settings/download`）
2. 找到 **LunaBox** 设置项
3. 取消勾选**显示 LunaBox 下载按钮**

禁用后，下载面板中每个文件行的 Aria2 按钮和普通下载按钮旁边，将不再出现 LunaBox 图标按钮。

## 使用 LunaBox 下载

1. 在任意游戏页面点击**下载**，打开下载面板
2. 找到你想要的资源和文件
3. 点击**月亮图标**按钮，将下载任务推送到 LunaBox
4. 如果需要 Turnstile 验证，在弹出窗口中完成验证——验证通过后任务会自动发送给 LunaBox
5. 切换到 LunaBox，下载即已开始

每次推送时，LunaBox 会收到以下信息：

| 字段       | 值                                     |
| ---------- | -------------------------------------- |
| 下载链接   | 带签名的限时直链                       |
| 文件名     | Shionlib 中的原始文件名                |
| 压缩格式   | 根据文件扩展名自动识别                 |
| 文件大小   | 精确字节数，用于校验                   |
| 校验值     | SHA-256 或 BLAKE3 哈希，用于完整性校验 |
| 游戏标题   | 游戏的日语标题                         |
| 元数据来源 | Bangumi（用于游戏库匹配）              |

## 常见问题

**点击 LunaBox 按钮没有反应**

请确保 LunaBox 已安装并正在运行。安装程序必须已注册 `lunabox://` 协议处理程序。若 LunaBox 在安装完成前已打开，请重启后再试。

**下载任务没有出现在 LunaBox 中**

检查浏览器或系统安全设置是否拦截了 `lunabox://` 协议。部分系统会弹出确认对话框，询问是否允许打开此链接——点击**打开**或**允许**即可。

**Turnstile 验证后下载没有开始**

Turnstile 弹窗在验证通过后会自动关闭。如果下载仍未开始，再次点击月亮图标即可——本次会话中签名链接已缓存，无需再次验证。
