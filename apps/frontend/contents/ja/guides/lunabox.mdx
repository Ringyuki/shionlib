## LunaBox とは

[LunaBox](https://box.lunarain.site) は高速・美麗・多機能な軽量ビジュアルノベル管理ツールです。ダウンロード機能だけでなく、ゲームライブラリの整理、プレイ時間の記録、さらにはビルトイン AI アシスタントによるプレイ習慣の分析まで行えます。

主な機能：

- **ゲーム管理** — カスタム分類と柔軟なメタデータ管理でライブラリを整理
- **プレイ時間トラッキング** — セッションを自動記録し、多次元の統計・グラフを生成
- **AI 分析** — ビルトイン AI がプレイ習慣を分析し、エンターテイメントレポートを生成
- **クラウドバックアップ** — S3・OneDrive 対応で安全なデータ同期・バックアップ
- **ダウンロード連携** — 自動解凍・チェックサム検証・レジューム対応

## LunaBox のインストール

公式サイトから LunaBox をダウンロード・インストールしてください：**https://box.lunarain.site**

LunaBox はインストール時にカスタムプロトコルハンドラー（`lunabox://`）を登録します。Shionlib はこのプロトコルを通じてダウンロードタスクを LunaBox に送信します。

> LunaBox は現在 **Windows** のみ対応しています。モバイルデバイスでは LunaBox ボタンは表示されません。

## Shionlib で LunaBox ボタンを有効にする

LunaBox ダウンロードボタンはデフォルトで非表示です。有効にする手順：

1. **設定** → **ダウンロード**（または `/user/settings/download`）を開く
2. **LunaBox** セクションを探す
3. **LunaBox ダウンロードボタンを表示**にチェックを入れる

有効にすると、ダウンロードパネルの各ファイル行に、Aria2 ボタンと通常ダウンロードボタンの隣に月アイコンボタンが表示されます。

## LunaBox でダウンロードする

1. ゲームページで**ダウンロード**をクリックしてダウンロードパネルを開く
2. ダウンロードしたいリソースとファイルを見つける
3. **月アイコン**ボタンをクリックしてダウンロードタスクを LunaBox に送信する
4. Turnstile 認証が必要な場合はポップアップで完了する — 認証後、タスクは自動的に LunaBox に送られます
5. LunaBox に切り替えると、ダウンロードが開始されています

送信される情報：

| フィールド       | 値                                          |
| ---------------- | ------------------------------------------- |
| ダウンロード URL | 署名付き期限付きダイレクトリンク            |
| ファイル名       | Shionlib 上の元のファイル名                 |
| 圧縮形式         | ファイル拡張子から自動判別                  |
| ファイルサイズ   | 検証用の正確なバイト数                      |
| チェックサム     | 整合性確認用 SHA-256 または BLAKE3 ハッシュ |
| ゲームタイトル   | ゲームの日本語タイトル                      |
| メタデータソース | Bangumi（ライブラリマッチング用）           |

## トラブルシューティング

**LunaBox ボタンをクリックしても何も起きない**

LunaBox がインストールされ、起動していることを確認してください。インストーラーによって `lunabox://` プロトコルハンドラーが登録されている必要があります。インストール完了前に LunaBox を起動していた場合は再起動してください。

**LunaBox にダウンロードタスクが表示されない**

ブラウザまたは OS のセキュリティ設定が `lunabox://` プロトコルをブロックしていないか確認してください。システムによっては「このリンクを開きますか？」という確認ダイアログが表示される場合があります。**開く** または **許可** をクリックしてください。

**Turnstile 認証後にダウンロードが始まらない**

Turnstile ポップアップは認証完了後に自動で閉じます。それでもダウンロードが開始されない場合は、月アイコンをもう一度クリックしてください。セッション中は署名済みリンクがキャッシュされているため、再認証は不要です。
