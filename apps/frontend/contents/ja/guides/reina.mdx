## ReinaManager とは

[ReinaManager](https://reina.huoshen80.top) は、ローカルゲームの整理、複数サイトからのメタデータ統合、プレイ時間の自動記録などをサポートする、軽量で使いやすい美少女ゲーム / ビジュアルノベル管理ツールです。

主な機能：

- 🌐 **多源データ統合** — 複数の API からゲームのメタデータを取得・統合して表示
- 🔍 **強力な検索** — ゲームタイトル、別名、カスタム名、その他のメタデータからゲームを検索
- 🗂️ **絞り込み・ソート** — 取得元、ステータス、タグなど多次元でゲームをフィルタリングおよび並べ替え
- 📚 **コレクション管理** — グループ分けやカテゴリ分けでゲームライブラリを整理し、ドラッグ＆ドロップによる並べ替えにも対応
- 🎮 **プレイ時間トラッキング** — ゲームセッションを自動記録し、詳細なプレイ時間統計と履歴を提供
- 🎨 **カスタマイズ** — ゲームカバー、タイトル、概要、タグなどの情報をカスタマイズして、自分だけのゲームライブラリを作成
- 💾 **セーブデータバックアップ** — ゲームのセーブデータを手動および自動でバックアップ可能
- 🛠️ **ツール連携** — ゲーム起動時に Locale Emulator による地域変更や Magpie による拡大表示を連携
- 📥 **ダウンロード連携** — Shionlib から送信されたゲームダウンロードタスクを受信し、ワンクリックでライブラリに追加

## ReinaManager のインストール

以下のページから ReinaManager をダウンロードできます：

- [ReinaManager クイックスタート](https://reina.huoshen80.top/guild/start/quick-start)

- **インストーラー版**: 一般ユーザーに推奨されます。今後の自動更新に対応しています。
- **ポータブル版**: ZIP 圧縮ファイルをダウンロードして展開するだけで使用できます。可搬性メディアでの利用に適していますが、今後のアップデートは手動操作が必要になる場合があります。

## Shionlib で ReinaManager を無効または有効にする

ReinaManager はデフォルトでダウンロードファイルのプッシュメニューに表示されます。

無効にする手順：

1. Shionlib の**設定**を開く
2. **ダウンロード**設定に入る
3. **ReinaManager** を探す
4. **プッシュメニューに ReinaManager を表示**をオフにする

オフにすると、ファイルプッシュメニューに ReinaManager が表示されなくなります。

## ReinaManager でダウンロードする

1. ゲームページで**ダウンロード**をクリックし、ダウンロードパネルを開く
2. ダウンロードしたいリソースとファイルを見つける
3. ファイル行の右側にある**紙飛行機アイコン**をクリックする
4. プッシュメニューから **ReinaManager** を選択する
5. 提示に従って Turnstile 認証を完了する
6. ブラウザが ReinaManager を開く許可を要求します
7. ReinaManager 内でゲーム情報とインストール先を確認する
8. 確認後、ダウンロードタスクを作成する

タスクを受信すると、ReinaManager は以下を行います：

1. ファイルをダウンロードし、ファイルサイズとハッシュ値を検証
2. 7Z、ZIP、RAR などの一般的な形式のアーカイブを解凍
3. アーカイブ内の不要な外側フォルダーを自動的に除去
4. ゲームの起動プログラムをスキャンして識別
5. Bangumi およびオプションの VNDB データを使用して Mixed メタデータを取得
6. Bangumi ID に基づいて既存のゲームとマッチング
7. 既存のゲームを更新、または一度に完全なローカルゲームを作成
8. タスクと最終的なゲームを関連付け

## 送信される情報

送信ごとに、ReinaManager は以下の情報を受信します：

| フィールド       | 内容                                                          |
| ---------------- | ------------------------------------------------------------- |
| ダウンロード URL | 署名付きの期限付きダイレクトリンク                            |
| ファイル名       | Shionlib 上の元のファイル名                                   |
| 圧縮形式         | 7Z、ZIP、RAR などのファイル形式                               |
| ファイルサイズ   | ファイルの正確なバイト数                                      |
| チェックサム     | SHA-256 または BLAKE3 ハッシュ                                |
| ゲームタイトル   | ゲームのタイトル                                              |
| resource_id      | 今回送信されたリソースを識別するための Shionlib 内リソース ID |
| Bangumi ID       | ゲームのマッチングおよびメタデータ取得用                      |
| VNDB ID          | オプション。Mixed メタデータ統合用                            |

Bangumi ID は必ずタスクとともに送信されます。VNDB ID は Shionlib のエントリーが VNDB に関連付けられている場合にのみ送信されます。

## トラブルシューティング

### プッシュメニューで ReinaManager を選んでも何も起きない

まず、アプリのログで `reinamanager プロトコル` に関連する内容を確認してください：

- アプリは通常、起動時にプロトコル登録を自動的に登録または修復します
- ログにエラーがある場合は、まず ReinaManager を再起動してみてください
- それでも反応がない場合は、ログを添えて作者にお問い合わせください

### ReinaManager にダウンロードタスクが表示されない

以下の点を確認してください：

- ブラウザがカスタムプロトコルをブロックしていないか
- ReinaManager のインストール確認ウィンドウが表示されていないか
- 期限付きダウンロードリンクの期限 commercial 切れていないか

### ReinaManager を事前起動していなくても、直接送信できますか？

はい、可能です。

ReinaManager を選択すると、システムが自動的にアプリを起動してダウンロードタスクを渡します。

### Turnstile 認証後にダウンロードが始まらない

プッシュメニューを再度開き、ReinaManager をもう一度選択してください。

署名付きリンクがまだ有効期間内であれば、通常は再認証の必要はありません。

### ダウンロード途中に「リンクの期限が切れました」と表示される

期限付きダウンロードリンクには有効期限があります。Shionlib から再度ファイルを送信すると、新しいダウンロードリンクが生成されます。
